# 청계중 3학년 시험 대비 학습실

화성 청계중학교 3학년 2학기 시험 대비용 웹 학습 자료 뷰어 (수학 / 과학 / 사회).
PC·모바일 브라우저에서 `index.html` 을 열면 바로 사용할 수 있습니다. (GitHub Pages 배포 가능)

## 기능
- 과목별 탭 / 검색 / 상태(미완료·완료·중요·헷갈림) 필터
- 인포그래픽·PDF·영상·음성(배속 조절)·학습앱 뷰어, PPTX 다운로드
- 단원별 공부 완료 / 중요 / 헷갈림 표시, 메모
- 시험 D-day, 하루 학습량 계산, 과목별 진도, 최근 7일 공부 시간
- 뽀모도로 집중 타이머 (공부 기록 자동 반영)
- 수학 핵심 공식 정리, 평균·분산·표준편차 계산기, 시험 전 체크리스트·공부 팁
- 랜덤 복습, 다크 모드, 진도 백업/복원

## 자료 추가·변경
자료 파일(png/pdf/pptx/mp4/m4a/html)을 폴더에 넣고 아래를 실행하면 `data.js`와 `thumbs/`가 갱신됩니다.

```
pip install pillow
python build_data.py
```

> 진도·메모는 브라우저(localStorage)에 저장됩니다.
